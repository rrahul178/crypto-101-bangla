# Crypto 101 বাংলা

Next.js 14 + TypeScript + Tailwind + Recharts। Database ছাড়া; অগ্রগতি localStorage-এ।

```bash
npm install
npm run dev     # http://localhost:3000
npm run build
```

## Deploy
GitHub-এ push → Vercel-এ **Import Git Repository** → Deploy।

## কনটেন্ট বদলানো
`data/modules.ts`-এ মডিউল ও কুইজ প্রশ্ন সম্পাদনা করুন।
